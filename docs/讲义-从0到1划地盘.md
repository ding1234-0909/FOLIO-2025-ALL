# 讲义：从 0 到 1 划地盘（操作手册版）

> 把游戏里一块空地，用混元 3D 生成的中国风木栅栏围起来，还能开车进出。
> 作者：丁浩宸
>
> **这份文档是操作手册，每一步告诉你：打开什么、改什么、执行什么命令、看到什么算成功。**

---

## 准备工作（大家先把环境拉起来）

每个人先在自己电脑上跑：

```bash
# 1. 克隆仓库
git clone https://github.com/YeJUN1/FOLIO-2025-ALL.git ~/Desktop/code/FOLIO-2025-ALL
cd ~/Desktop/code/FOLIO-2025-ALL

# 2. 装依赖
npm install --force

# 3. 跑起来
npm run dev
```

然后浏览器打开 http://localhost:5173/ ，应该能看到游戏画面。

## Step 1 · 给混元 3D 写栅栏 prompt（不写代码，写自然语言）

**目标**：告诉 AI 我要一个啥样的栅栏。

### 操作

**打开文件**：`scripts/hunyuan/manifest.json`

**找到 `assets` 数组，在第一个元素之前（也就是 `assets` 这个 `[` 之后、第一项之前），复制粘贴以下内容：**

```json
{
    "key": "woodFence",
    "name": "木栅栏",
    "enabled": true,
    "prompt": "中国古典园林木栅栏，独立构件，长2米、高1米，深棕色实木，竖向木条均匀排列，上下两道横梁，两端立柱齐平便于首尾拼接，无背景，无地面，真实比例，游戏环境资产",
    "normalize": { "axis": "y", "target": 1.0 },
    "rotationFix": [0, 0, 0],
    "collider": "cuboid",
    "notes": "地块围栏模块"
},
```

### 看到什么算成功

保存 `manifest.json`，文件没红色波浪线（JSON 格式正确）。

### prompt 里每部分在说啥（讲给同学听）

| 短语 | 作用 |
|---|---|
| 中国古典园林 | 定风格（不是美式 ranch 那种） |
| 长2米、高1米 | 告诉 AI 尺寸（不然它瞎做） |
| 深棕色实木，竖向木条均匀排列 | 细节 |
| 两端立柱齐平便于首尾拼接 | **关键** —— 栅栏要能首尾连起来 |
| 无背景，无地面 | **关键** —— 我要的是栅栏本身，不要它带着花园背景 |
| normalize: axis="y", target:1.0 | 生成后代码会把它缩到 1 米高 |
| collider: cuboid | 要物理碰撞，能挡人挡车 |

## Step 2 · 混元 3D 官网生成 GLB

**目标**：把 Step 1 写的 prompt 变成一个 3D 模型文件（.glb）。

### 操作

1. **打开网页**：https://3d.hunyuan.tencent.com/
2. **登录**：右上角登录（微信扫一下或 QQ）
3. **点创建**：页面中间的 **"+ 创建"** 按钮
4. **粘 prompt**：把 Step 1 里那个长 prompt 粘进去
5. **选模型**：选 **3.1 Pro**（效果最好，免费额度够）
6. **点生成**
7. **等 10-30 秒** → 出现 3D 预览
8. **下载**：预览下方点 **"下载"**，选 **GLB 格式**
9. **下载的文件一般叫 `woodFence.glb` 或一串 md5 数字**，放到本地：

```bash
# macOS 下一般在 Downloads 文件夹
cp ~/Downloads/woodFence.glb ~/Desktop/code/FOLIO-2025-ALL/resources/hunyuan-raw/woodFence.glb
```

### 看到什么算成功

- `resources/hunyuan-raw/woodFence.glb` 存在，**大小在 30-60 MB 之间**（混元生成的资产面数高）
- 双击能在 macOS 预览里看到一个木栅栏模型

## Step 4 · 写 PlotFence.js（核心代码）

**目标**：让栅栏沿地块矩形周长摆一圈，下边中间留一个门。

### 操作

**新建文件**：`sources/Game/World/PlotFence.js`

**完整代码复制粘贴**：

```js
import * as THREE from 'three/webgpu'
import { Game } from '../Game.js'
import { InstancedGroup } from '../InstancedGroup.js'

export class PlotFence
{
    constructor()
    {
        this.game = Game.getInstance()
        this.moduleKey = 'woodFence'
        this.fallbackOriginHeight = 1.04
        this.gateLength = 4.2           // 门宽 4.2 米

        this.setBoundary()              // ① 写死矩形边界
        this.load()                     // ② 加载栅栏 GLB
    }

    // ① 矩形边界 —— 贴地块内侧，下边中间开门
    setBoundary()
    {
        const rect = {
            left:   - 6.5,
            right:    46.5,
            top:     - 73.3,           // 上边（z 值小）
            bottom:  - 40.3,           // 下边（z 值大，门开在这）
        }

        const gateCenterX = (rect.left + rect.right) / 2   // 门的 x 位置 = 矩形中心
        const gateHalf    = this.gateLength / 2             // 2.1 米
        const gateRightX  = gateCenterX + gateHalf          // 门右端 x
        const gateLeftX   = gateCenterX - gateHalf           // 门左端 x

        // 6 个角点：上边 → 右边 → 下边右半 → (4.2m 开口) → 下边左半 → 左边
        this.boundary = [
            [ rect.left,   rect.top ],      // 左上
            [ rect.right,  rect.top ],      // 右上
            [ rect.right,  rect.bottom ],   // 右下
            [ gateRightX,  rect.bottom ],   // 门的右端
            [ gateLeftX,   rect.bottom ],   // 门的左端（中间 4.2m 无栅栏）
            [ rect.left,   rect.bottom ],   // 左下
        ]
    }

    // ② 加载栅栏模型（优先混元生成的，没有就用游戏自带的兜底）
    async load()
    {
        let model = null
        let originHeight = 0

        try
        {
            const resources = await this.game.resourcesLoader.load([
                [ this.moduleKey, `garden/${this.moduleKey}.glb?cb=1`, 'gltf' ]
            ])
            model = resources[this.moduleKey].scene
        }
        catch(e) { /* 失败，走下面的兜底 */ }

        if(model)
        {
            originHeight = 0   // normalize 之后 pivot 在底面中心
        }
        else
        {
            // 兜底：用游戏自带的 fences.glb
            model = this.game.resources.fencesModel.scene.children[0].clone()
            originHeight = this.fallbackOriginHeight
            console.log('PlotFence > 未找到 garden/woodFence.glb，回退使用游戏原生栅栏')
        }

        this.build(model, originHeight)   // ③ 开始摆
    }

    // ③ 摆栅栏 + 建碰撞
    build(_model, _originHeight)
    {
        _model.castShadow = true
        _model.receiveShadow = true

        // 实测栅栏段长度
        const box = new THREE.Box3().setFromObject(_model)
        const lengthX = box.max.x - box.min.x
        const lengthZ = box.max.z - box.min.z
        this.segmentLength = Math.max(0.5, Math.max(lengthX, lengthZ))   // 1.572 m
        this.moduleYawOffset = lengthZ > lengthX ? Math.PI / 2 : 0       // 长度在 Z 轴就转 90°

        // 从模型里提取 cuboid 碰撞体描述
        const descriptions = this.game.objects.getFromModel(_model, {}, {})
        const colliderOffsets = descriptions[1] ? descriptions[1].colliders : []
        this.game.materials.updateObject(_model)

        // 沿 boundary 等距重采样，跳过门那段
        const points = this.resampleClosed(this.boundary, this.segmentLength)

        // 刷新物理查询管线（确保射线能命中刚加的地形）
        this.game.physics.world.queryPipeline.update(this.game.physics.world.colliders)

        this.references = []
        this.colliders = []

        for(let i = 0; i < points.length; i++)
        {
            const a = points[i]
            const b = points[(i + 1) % points.length]

            const midX = (a[0] + b[0]) * 0.5
            const midZ = (a[1] + b[1]) * 0.5
            const groundY = this.getGroundElevation(midX, midZ)   // ④ 贴地射线

            // 这段栅栏朝哪摆
            const quaternion = new THREE.Quaternion().setFromAxisAngle(
                new THREE.Vector3(0, 1, 0),
                Math.atan2(- (b[1] - a[1]), b[0] - a[0]) + this.moduleYawOffset
            )

            const reference = new THREE.Object3D()
            reference.position.set(midX, groundY + _originHeight, midZ)
            reference.quaternion.copy(quaternion)
            reference.needsUpdate = true
            this.references.push(reference)

            // ⑤ 生成物理碰撞体（cuboid）
            for(const collider of colliderOffsets)
            {
                const offset = new THREE.Vector3(collider.position.x, collider.position.y, collider.position.z)
                offset.applyQuaternion(quaternion)
                this.colliders.push({
                    shape: collider.shape,
                    parameters: [ collider.parameters[0], collider.parameters[1], collider.parameters[2] ],
                    position: {
                        x: midX + offset.x,
                        y: groundY + _originHeight + offset.y,
                        z: midZ + offset.z
                    },
                    quaternion: { x: quaternion.x, y: quaternion.y, z: quaternion.z, w: quaternion.w },
                    category: 'object'
                })
            }
        }

        // ⑥ 实例化渲染（一个 Mesh 画 100 多段）
        this.instancedGroup = new InstancedGroup(this.references, _model)

        // ⑦ 物理：单个 fixed 刚体 + 所有 cuboid 合并进去
        if(this.colliders.length)
        {
            this.object = this.game.objects.add(null, {
                type: 'fixed',
                friction: 0.7,
                restitution: 0.1,
                colliders: this.colliders
            })
        }
    }

    // ③-辅助：等距重采样 + 跳过门
    resampleClosed(_poly, _spacing)
    {
        const n = _poly.length
        const cumulative = [ 0 ]
        const segmentLengths = []

        for(let i = 0; i < n; i++)
        {
            const a = _poly[i]
            const b = _poly[(i + 1) % n]
            const len = Math.hypot(b[0] - a[0], b[1] - a[1])
            segmentLengths.push(len)
            cumulative.push(cumulative[i] + len)
        }

        // 门那段 ≈ gateLength 的段 → 跳过所有落在其上的采样点
        const gateLength = this.gateLength
        const isGateSegment = (len) => Math.abs(len - gateLength) < 0.5

        const perimeter = cumulative[n]
        if(perimeter <= 0) return []

        const count = Math.max(3, Math.round(perimeter / _spacing))
        const step = perimeter / count

        const points = []
        let index = 0

        for(let i = 0; i < count; i++)
        {
            const distance = i * step

            while(index < n - 1 && cumulative[index + 1] < distance)
                index++

            if(isGateSegment(segmentLengths[index]))
                continue   // ← 关键：跳过门

            const a = _poly[index]
            const b = _poly[(index + 1) % n]
            const segLen = segmentLengths[index]
            const t = segLen <= 1e-9 ? 0 : (distance - cumulative[index]) / segLen

            points.push([ a[0] + (b[0] - a[0]) * t, a[1] + (b[1] - a[1]) * t ])
        }

        return points
    }

    // ④ 贴地射线：从 y=50 向下打 100m，命中地形 → 拿到真实地面高度
    getGroundElevation(_x, _z)
    {
        const startY = 50
        const ray = new this.game.RAPIER.Ray(
            { x: _x, y: startY, z: _z },
            { x: 0, y: - 1, z: 0 }
        )
        const hit = this.game.physics.world.castRay(
            ray, 100, true,
            undefined, undefined, undefined, undefined,
            (collider) => collider.collisionGroups() === this.game.physics.categories.floor
        )
        return hit ? startY - hit.timeOfImpact : 0
    }
}
```

### 代码结构速览（讲给同学听）

```
constructor()
  ├─ setBoundary()       写死 6 个角点（矩形 + 门开口）
  └─ load()              优先加载 woodFence.glb → 失败回退游戏原生
       └─ build()
            ├─ Box3 实测段长（1.572 m）
            ├─ resampleClosed()   等距重采样 + 跳过门位置
            ├─ 逐段 getGroundElevation()   贴地射线
            ├─ 算朝向 atan2(-dz, dx)
            ├─ InstancedGroup()   实例化渲染（GPU 只画一个 Mesh）
            └─ objects.add({ type:'fixed', colliders: [...] })   合并刚体
```

- 文件保存后 IDE 没报错（红色波浪线）
- 文件能被 import（没有 unresolved import 红线）

## Step 9 · 视角丝滑化（V 键第一视角）

**目标**：默认跟车视角 + 叠加鼠标微调 + 松手自动回归；加 V 键切第一视角。

### 操作

这步改动比较大，**建议直接用我写好的完整代码**。

**打开文件**：`sources/Game/View.js`

#### 9.1 · 加 MODE_COCKPIT 常量

找到 `static MODE_DEFAULT = ...` 那几行，在末尾加：

```js
static MODE_COCKPIT = 3
```

#### 9.2 · V 键注册（常驻）

找到 Keyboard 的 category 配置，确保 V 键在 `intro / wandering / walking / racing` 里都注册。

#### 9.3 · toggleMode() 三态循环

```js
toggleMode()
{
    if(this.mode === View.MODE_DEFAULT) this.setMode(View.MODE_COCKPIT)
    else if(this.mode === View.MODE_COCKPIT) this.setMode(View.MODE_FREE)
    else this.setMode(View.MODE_DEFAULT)
}
```

#### 9.4 · update() 里加 spring-mass 平滑

```js
// 硬算的目标角度（有 forward 微抖）
targetTheta = Math.atan2(-forward.x, -forward.z)   // DEFAULT 跟车：看车屁股
// targetTheta = Math.atan2(forward.x, forward.z)   // COCKPIT 第一视角：看车前面

// spring-mass 平滑（滤掉微抖）
thetaAccel = (targetTheta - baseTheta) * stiff - baseThetaVel * damp
baseThetaVel += thetaAccel * delta
baseTheta    += baseThetaVel * delta

// 最终角度 = 平滑值 + 用户微调
theta = baseTheta + yawOffset
phi   = basePhi   + pitchOffset

// 用户微调自动衰减（松手后 1 秒回归默认角度）
yawOffset   *= Math.exp(-delta * decayRate)
pitchOffset *= Math.exp(-delta * decayRate)
```

#### 9.5 · COCKPIT 相机位置平滑

```js
// 理想驾驶座位置 = 车头 + 上方 1.2 m
cockpitTarget = vehiclePos + forward * 0.5 + new THREE.Vector3(0, 1.2, 0)
// 平滑追（时间常数 20/s）
cockpitPosition.lerp(cockpitTarget, 1 - Math.exp(-delta * 20))
camera.position.copy(cockpitPosition)
```

### 参数对照（调这个 = 调手感）

| 模式 | stiff | damp | 手感 |
|---|---|---|---|
| DEFAULT 跟车 | 30 | 6 | 有惯性但不飘 |
| COCKPIT 第一视角 | 80 | 12 | 跟得紧 |

### 看到什么算成功

- 刷新游戏 → **车开起来** → 视角跟着车走，不抖
- **鼠标左键拖动** → 视角偏过去，松手自动回正
- **按 V** → 进入第一视角（车头位置）
- **再按 V** → 自由视角
- **再按 V** → 回到默认跟车
