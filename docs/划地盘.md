# 划地盘

> 游戏里多个玩家的地盘定义。每人一个地块，各自用不同风格的围栏围起来。

---

## 叶老师 · 左下角红框坐标标定（2026-10-13）

### 依据：游戏内坐标系统

- `sources/Game/Map.js` 的 `worldToMap()`：地图为线性映射，`mapX = x / 192 + 0.5`、`mapY = z / 192 + 0.5`（z 越大越靠图下方）
- `sources/Game/Terrain.js`：`this.size = 192`，即世界坐标 x/z 各覆盖 **[-96, 96]**，地图图中心 = 世界原点 (0, 0)
- 换算公式（地图百分比 ↔ 世界坐标）：`x = (pctX - 50) × 1.92`，`z = (pctY - 50) × 1.92`

### 红框范围（三种表示法）

| 表示法 | 范围 |
| --- | --- |
| 世界坐标（游戏内可直接用） | x ∈ [-95.6, -73.8]，z ∈ [74.9, 96]，约 21.8m × 21.1m |
| 地图百分比（对应 map-day.webp 显示区域） | left 0.2% → 11.6%，top 89.0% → 100% |
| 伪经纬度（[-96,96] 线性映射到全球经纬度，图上为北） | 中心 N 42.2° W 138.0° |

### 备注

- 红框基本落在**海面**上，框内只有一座小岛；若需要圈可通行的陆地，应向东北方向挪动后重新标定。

## 舒雯 · 西北角领地（TerritoryFence 石围栏）

### 范围（世界坐标）

| 项 | 值 |
| --- | --- |
| X 范围 | -96 ～ -37.2 |
| Z 范围 | -96 ～ -16.2 |
| 东边界线 | x = -37.2，从 z = -36.3（北端）到 z = -16.2（南端） |
| 位置 | 地图西北角，取手绘边界线以西，包含沿岸海面 |

### 判定方法

`x ≥ -96 && x ≤ -37.2 && z ≥ -96 && z ≤ -16.2`

### 围栏实现

- 类：`sources/Game/World/TerritoryFence.js`
- 资产：`static/garden/stoneFence.glb`（石围栏）
- 风格：沿不规则地块边界线围一圈，自动生成石栏杆段
- 来源：`sources/Game/Territory.js`

| 段数 | 90 段（闭合） |
| 兜底 | 未找到 woodFence.glb 时自动回退到 `static/fences/fences.glb` |

### 碰撞

- 90 段 cuboid 合并成 **单个 `fixed` 刚体**
- friction: 0.7，restitution: 0.1
- 每段中点从 y=50 向下射线命中地形（`categories.floor`）取实际高度 → 栅栏贴地不悬空

### 代码实现

- 核心类：`sources/Game/World/PlotFence.js`
- 挂载：`sources/Game/World/World.js` → `this.plotFence = new PlotFence()`

### 开局

| 项 | 值 |
| --- | --- |
| 出生点 | `VITE_PLAYER_SPAWN=fence` |
| 坐标 | `(15, 4, -60)`，地块中央偏上（距四周边界 5~12 m） |
| 开局状态 | 直接开车（`Character.enterVehicle()`），蜘蛛侠隐藏 |

### 视角

| 项 | 值 |
| --- | --- |
| 默认 | 跟车视角（theta 平滑追 forward，spring-mass，stiff=30/damp=6） |
| V 键 1 | **COCKPIT 第一视角**（车头位置 + 0.5m + 上方 1.2m，相机位置 lerp 减震，stiff=80/damp=12） |
| V 键 2 | 自由视角 |
| V 键 3 | 回到默认 |
| 鼠标左键拖动 | 叠加微调 offset（yawOffset/pitchOffset），松手后自动衰减回归 |

### 实测

| 项 | 值 |
| --- | --- |
| segmentLength | 1.5723 m |
| 段数 | 90 |
| 碰撞体 | 90 cuboid · 单个 fixed 刚体 |

| originHeight | 0（normalize 后 pivot 归底面中心） |
| moduleYawOffset | 0（长度已在 X 轴，无需旋转） |
